## 유효성 검사

### 근무자
- 근무자 중복 금지
- 근무자는 평일1번, 휴일1번
- 근무자 이름은 5자이하
- 근무자 수는 5명이상 35명 이하


## 비즈니스 로직

# 실행 순서
올바르지 않은 입력시 `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.` 출력하고 다시 입력받기

휴일 근무 사원 입력이 올바르지 않으면 평일 근무 사원 입력부터 다시.
1. 월, 요일 입력
    - 해당 월 1일이 해당 요일인거임.
    - 월이 1~12인지
    - 요일이 해당 월의 날짜수에 해당되는지

2. 평일 근무 사원 입력
    - 근무자가 중복되어 있지는 않은지.
    - 근무자 이름이 모두 5자 이하인지.
    - 근무자 수가 5명 이상 35명 이하인지.
3. 휴일 근무 사원 입력
    - 평일근무사원과 휴일근무사원 목록이 서로 일치하는지.

4. 근무 순서 출력.
    - 평일이면서 법정공휴일의 경우에만 요일 뒤에 (휴일) 표기
let month;
    let day;
    let dayWorkers;
    let weekWorkers;
